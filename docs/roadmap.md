# Roadmap

## Phase 1: Codec Core

- Hoàn thiện wrapper encoder/decoder.
- Chuẩn hóa Unicode/tokenizer.
- Bảng KHD có metadata.

## Phase 2: Test Suite

- 5.000 từ đơn.
- 10.000 từ ghép.
- 1.000 địa danh.
- 500 câu hành chính.
- 500 câu kỹ thuật.
- 500 mã sản phẩm/ký hiệu.

## Phase 3: NLP Benchmark

- Khôi phục dấu từ văn bản không dấu.
- Sửa lỗi ASR tiếng Việt.
- Sửa lỗi OCR tiếng Việt.
- Tìm kiếm địa danh/GIS.

## Phase 4: ID/GIS/RFID

- Chuẩn hóa payload QR/NFC/RFID.
- Tạo demo truy xuất nguồn gốc.
- Tạo demo GeoJSON/Digital Twin.

## Phase 5: Multi-language Packages

- Python package.
- REST API.
- Browser package.
- QGIS plugin prototype.
